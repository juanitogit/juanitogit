## 🚀 Proyectos Destacados
*🔍 Abrir ficha técnica de cada proyecto*

### 🔬 VIANova
- **Problema:** Fragmentación y falta de datos precisos en tiempo real sobre los flujos de movilidad urbana inteligente.
- **Arquitectura:** TypeScript · React · Chatbot IA · Tailwind CSS · Despliegue en Producción
- **Resultado:** Plataforma web en producción que optimiza los flujos de movilidad urbana, integrando un asistente conversacional (Chatbot IA) que guía al usuario en tiempo real dentro del ecosistema de transporte. (En proceso de publicación para IEEE).

### 🌱 BioSmart
- **Problema:** Desperdicio de recursos e inseguridad alimentaria en sistemas de cultivos tradicionales.
- **Arquitectura:** Go · Typescript · Chatbot IA · Cultivos Verticales · Servicios de Notificación
- **Resultado:** Ecosistema inteligente automatizado con agentes de IA (GopherMind AI) para monitoreo y procesamiento de datos agrícolas en tiempo real, control automatizado de recursos y alertas críticas. (Postulación IEEE).

### 🌍 EcoGuardian
- **Problema:** Ausencia de monitoreo activo y plataformas ágiles para reporte y gestión de incidentes y métricas ecológicas críticas.
- **Arquitectura:** Capacitor · TypeScript · React · Chatbot IA · Mobile UI · Interconectividad
- **Resultado:** Plataforma web y móvil nativa integral en producción. Chatbot enfocado en resolver consultas ambientales y reportes de alertas con métricas críticas accesibles multiplataforma. (Postulación IEEE).

### 🪐 AxionReality
- **Problema:** Dificultad para generar e interactuar de forma inmersiva y automatizada con modelos 3D en entornos virtuales.
- **Arquitectura:** TypeScript · React · Inteligencia Artificial · Realidad Aumentada (AR) · Modelado 3D
- **Resultado:** Plataforma inmersiva con generación automatizada de recursos mediante IA, integrando AR para visualización en el entorno real (mediante QR) con rendimiento de gráficos interactivos de alta fidelidad optimizado en producción.
